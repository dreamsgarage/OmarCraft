### Maintainer notes
Unofficial launcher and installer for the ArtCraft Craft apps by Storyteller (PhotoCraft, FilmCraft, WordCraft and ten more) and ArtCraft Studio as a web app. A bar widget opens a picker built on omarchy-menu-select: launch installed apps, install one app or a group, update. Installs use only the prebuilt <id>-bin AUR packages through yay in a visible Omarchy floating terminal, so nothing is compiled and pacman owns every app. No sudo or pkexec is called by the plugin; the password prompt is yay's own, in the open terminal. Network use: the app catalog from raw.githubusercontent.com (storytold/craft-launcher) and versions from the AUR RPC, cached 24 hours. The plugin does not change user configuration on its own: the Omarchy menu section and the keybinding are opt-in commands documented in the README.
